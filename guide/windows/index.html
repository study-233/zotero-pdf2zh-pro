Windows 安装

适用于 Windows 10/11 x64。安装 EXE 内置服务程序，首次安装仍需联网准备 Python 和翻译依赖。

第一步：下载并打开安装器

  1. 打开 最新 Release，展开发布页底部的 Assets。
  2. 下载 zotero-pdf2zh-pro-windows-x64-setup.exe，同时下载 zotero-pdf2zh-pro.xpi，稍后装入 Zotero。
  3. 双击安装 EXE。控制中心、安装文件和配套服务程序已内置，无需解压。

第二步：选择安装位置并安装

  1. 在向导中确认安装位置、登录自启和自动更新选项，点击 “开始安装”。
  2. 下载文件时显示当前文件的实际字节数、百分比和速度；准备 Python 和依赖时，用活动指示器、步骤和已用时间表示正在处理，不显示无法计算的总体百分比。
  3. 安装完成后，点击 “打开控制中心”，等待出现 “翻译服务已就绪”。

默认安装到 %LOCALAPPDATA%\zotero-pdf2zh-pro，首次安装可以选择其他磁盘。 已有安装会保留目录、配置、数据和自启选择；同版本安装可修复，高版本安装可升级，禁止降级。

从 v1.8.2 或更早版本升级时，先等待翻译完成，再从旧控制中心停止服务后运行新安装器。旧服务尚不支持维护保护，正在运行时安装器会保留已准备的新环境并提示停止服务，不会强制中断翻译。 安装或更新期间可以后台运行，在托盘重新打开窗口可继续查看进度。Python 和依赖按文件显示下载量、速度和百分比；无法取得总量时显示当前步骤和耗时，不显示循环进度条。“操作详情”在当前页展开，可滚动查看并复制日志；向上滚动会暂停跟随，点击“回到最新”恢复。失败时详情自动展开，可以重试或打开日志。设置页的“关于”提供版本、License 与致谢。

第三步：保持服务运行并安装插件

服务地址保持 http://127.0.0.1:8890，接着完成安装 Zotero 插件。

  • 关闭主窗口会销毁面板并保留托盘；重新打开控制中心可继续查看状态。
  • 退出控制中心也不会停止已经运行的翻译服务。需要停止时，点击“停止服务”。
  • 登录自启默认开启，登录 Windows 时自动启动服务并进入托盘，可随时关闭。
  • 设置 → 外观与启动可切换跟随系统、浅色或深色主题。更新、安装目录、日志和维护工具也在设置中。
  • 安装通常无需管理员权限；若 8890 端口被占用，先检查是否已有服务运行。

如果控制中心打不开

  • 原生控制中心支持 Windows 10/11 x64，不依赖 WebView2 或额外 VC++ 运行库。首次安装翻译服务仍需联网准备 Python 和依赖。
  • 如果旧版提示缺少 WebView2Loader.dll，请下载新版 Windows 安装 EXE，双击后按向导安装或升级；无需先卸载原版，已有配置和翻译记录会保留。
  • 当前 EXE 未签名，Windows SmartScreen 可能提示风险。请只从本项目 Release 下载，并核对发布页提供的 SHA-256。
  • 图形界面仍无法使用时，可查看 Windows 说明，从安装目录的 bin 文件夹使用 install.cmd、start-server.cmd 或 view-log.cmd 等故障恢复入口。
