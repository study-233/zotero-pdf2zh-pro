Linux 与 Docker

Linux / Docker

Linux 可参考上文 uv 方式。已有 Docker 环境时，在本仓库根目录（含 compose.yaml）执行：

docker compose up --build -d

服务默认使用 8890 端口，数据和缓存通过 Compose 中的卷映射保存。端口绑定范围以 compose.yaml 为准；仅本机使用时可将端口映射限定为 127.0.0.1:8890:8890。 Docker 不会自动继承宿主机的证书信任库，需要私有 CA 时应在容器中配置。 服务端接口与兼容性说明见 server/README.md。

源码部署与发布流程见开发维护笔记。
