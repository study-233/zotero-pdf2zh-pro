划词精读与翻译记忆

打开可选中文字的原始 PDF，划选单词或句子，结果会自动显示。在线与离线查词都不需要 Python 服务；选句翻译和语境解释需要本地服务运行。在 设置 → 选文翻译 → 触发方式 中选择“点击翻译”后，先划选，再点击原生选区工具栏的“翻译”，点击前不会发起请求。已有用户的触发方式与显示位置保持原值。

查单词与短语

  1. 选中英文单词（含词形变化、连字符和撇号），稍等约 0.4 秒，默认打开“词典”。2–3 个英文词默认打开“翻译”，也可手动切到“词典”查短语；更长句段或其他语言只显示“翻译”。
  2. 查看中文释义、音标和词性；展开可查看更多释义及双语例句。
  3. 单词需要译文时，切到“翻译”才发起翻译请求。同一选文在两页签间切换会保留已完成的结果；新划选会重新判断默认页签。
  4. 点击“复制”保存结果，继续划选会更新同一张卡片。

新安装默认使用有道在线词典；升级保留原来的选择，包括旧版默认的 ECDICT。“词典”页签下的来源栏可选择有道、必应在线词典、ECDICT 或柯林斯；与“翻译”页签的来源分别记忆。在线来源只查所选词典；离线先查本地，未命中才查询设置中的在线后备（默认有道）。网络错误与词库读取错误会显示重试入口，不自动调用模型。手工术语表命中单独标注。

内置约 5 万条英汉词条，离线释义无需联网；柯林斯需先下载。精确词条优先，支持常见复数、过去式和进行时还原。词典提供英美音标时分别显示；词条显示后会联网预加载发音，点击按钮才播放。切换词语或关闭卡片会停止播放并取消不再需要的下载；已加载的音频短暂保留在内存中，重复播放或切换显示位置无需再次下载。默认展开最多三条释义和一条例句，查询词及原形在例句中高亮；其他内容可展开。

翻译句子与段落

选中句段即可翻译。主结果只对应选文；匹配到的整段译文收在“已有段落译文”，复制主结果不会带上整段参考。

在 设置 → 选文翻译 → 翻译来源 中统一选择必应、跟随全文模型或已保存的具体模型：

服务 需要准备 使用方式
必应（默认） 联网并运行本地服务，无需 Key 只发送选文与语言；失败时显示错误，不会自动调用付费模型
模型翻译 已保存的 OpenAI 兼容或 Codex 配置 可跟随全文配置，也可独立选择；按需结合页面上下文

优先复用本地缓存、精确匹配的全文译文和术语；重复选择通常无需再次请求。点击“重新翻译”使用当前配置重新生成，失败时保留原结果。

独立划词模型不改变全文配置。删除所选配置后需重新选择；选择模型模式但尚未配置模型时使用必应基础翻译。

“翻译”页签下可以直接切换翻译来源，无需再单独选择服务与模型。AI 翻译、补充释义和语境解释共用所选模型；使用必应翻译时，在设置的“高级设置”中单独选择“AI 增强模型”。打开“原文 · 编辑后重译”，修正 PDF 断行、连字符或 OCR 错字，再点击“翻译”或按 Ctrl/Cmd + Enter。输入法组合期间不会提交。“取消”放弃编辑，“恢复划选原文”恢复 PDF 中的文字；修订文本不再匹配论文上下文时，需要重新划选才能使用语境解释。

AI 流式输出默认开启。支持的 OpenAI 兼容与 Codex 模型会逐步显示普通译文；必应文本翻译、AI 词典和语境解释完整返回。点击“停止生成”保留已输出文字供复制并标注“未完成”，不保存为成功缓存。失败后需要手动重试；明确不支持流式的模型可在“更多”中选择“使用普通模式重试”。旧服务端未声明流式能力时仍使用普通模式。切换页签、来源、选区或修订原文会取消失效请求，迟到结果不会覆盖当前内容；浮窗与侧栏之间切换保留结果与进行中的请求。

个人词典与语境解释

  • 缺词补充：所选词典及适用的在线后备都确实未命中时，先查个人词典，再按设置自动生成释义、用法和例句；可关闭“缺词时自动补充释义”。接口错误不触发补充；仍未收录或未配置模型时，保留提示与“翻译此词”入口，点击后才请求译文。
  • 结合上下文解释：点击后由划词模型解释选文在论文中的含义；需要页面上下文，读取失败时可重试。
  • 分别重翻、复制：通用释义、语境解释和句段译文各自独立，重翻时原结果继续显示。

AI 释义标注模型来源，保存到个人词典后可跨论文、跨模型复用；不会改写导入词典或术语表。必应基础译文不保存为详细词条。

模型翻译与语境解释按需读取当前页及相邻页，不扫描整篇论文；复杂多栏可能影响上下文。必应不发送论文上下文。

顶部图标依次提供固定（仅浮窗）、显示位置切换、更多与关闭（仅浮窗），悬停可查看说明。“清空结果”“恢复自动大小”“查看收藏”位于更多菜单；支持方向键、Home/End、Esc 和点击菜单外部关闭。

滚动和翻页不会关闭结果；未固定的浮窗在点击空白或切换论文时关闭。侧栏为每篇论文分别保留结果；不支持侧栏的窗口使用浮窗。连续划选只显示最后一次结果，长内容在卡片内滚动。

收藏与论文出处

单词和短语的词条旁提供收藏星标。可以先点击一条释义，选择收藏的译法；未选择时采用第一条结构化释义或当前结果。收藏保存当时的词条、已生成的语境含义、PDF 原始划选、修订查询、论文上下文、附件和页码，不额外调用模型。再次点击星标可取消当前附件、页码、选区和词语对应的收藏，收藏列表同步更新；同词在其他出处的收藏继续保留。通过“更多 → 更新收藏快照”显式替换快照。

在右侧“划词收藏”区查看当前论文或全部收藏，按词语、释义、文献标题搜索，查看详情、复制、删除或“回到原文”。跳转使用所属库和附件 key；附件变化时降级到页码，附件丢失或尚未下载时保留收藏并显示提示。收藏本地保存，不随 Zotero 云同步；首行保留范围筛选、搜索和更多菜单；在更多菜单中进行完整 JSON 导入或 JSON/CSV 导出，导入合并时保留本地冲突记录。空列表会区分尚无收藏与筛选无结果。

“加入术语表”是收藏详情中的独立操作。填写原词、译法和目标语言后保存；同词同语言已有不同译法时，可保留原值或显式替换。仅收藏不会改变全文翻译的术语。

下载与管理词典

  1. 打开 设置 → 选文翻译 → 高级设置，点击柯林斯扩展词库的 “下载并启用”。
  2. 等待下载完成，确认离线词典选为“柯林斯”。支持 37,375 个有效词条，下载约 10.9 MB。
  3. 已安装时可“检查更新”；也可通过“从文件导入”安装兼容的词库 JSON。

常用设置集中展示触发方式、显示位置、词典来源与翻译来源。默认折叠的“高级设置”提供 AI 补充释义、语境解释说明、流式显示、词库与缓存管理；在线回退仅在选择离线词典时出现。

下载无需本地服务。关闭设置页不会中止下载；退出 Zotero 会中止，之后可重试。下载、更新或导入失败保留旧词库；下载期间主动切换词典会保留你的选择。

未收录词由 ECDICT 兜底；读取异常时提示重新导入。词库“详情”显示版本、来源和安装信息，其中 945 条 AI 补充释义单独标注来源。数据与许可见词典来源说明。

缓存、备份与使用范围

数据 保存与清理
个人词典 保存生成的详细词条，不自动过期；“清空翻译缓存”会保留
选句与语境缓存 保存在服务端 selection-cache.sqlite3，最多 20,000 条，优先保留最近使用的结果
全文翻译记忆 保存在 translation-memory.sqlite3；删除任务或清空翻译缓存不会删除
柯林斯词库 保存在 Zotero 数据目录的 pdf2zhpro/dictionaries/，可随 Zotero 数据迁移
在线词典缓存 Zotero 数据目录的 pdf2zhpro/dictionary-cache-v1.json；成功结果 30 天、未命中 10 分钟，最多 2,000 条，网络错误不缓存；“清除在线词典缓存”单独清理
划词收藏 Zotero 数据目录的 pdf2zhpro/selection-favorites-v1.json 和 .bak 备份；串行、临时文件替换写入，清缓存不删除收藏

备份服务数据前先停止服务，保留上述两个数据库；个人词典和缓存不自动跨电脑同步。全文记忆按原 PDF 内容和目标语言匹配，历史任务仍保留输入 PDF 与检查点时可自动补建。

支持可选中文本的原 PDF；扫描件划词、译文附件反查、精确词级对齐、下载术语包查词及墨墨暂不支持。无法还原的旧排版内容以 ⟦原排版内容⟧ 标记。

查询记忆失败时先显示错误，不直接转为外部请求。若提示“本地服务仍返回段落译文”，在更新与维护中更新服务端。更多机制见服务端说明，功能验收见开发维护笔记。
