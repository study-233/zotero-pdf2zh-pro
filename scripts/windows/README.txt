zotero-pdf2zh-pro Windows 10/11 x64

快速开始

1. 下载 zotero-pdf2zh-pro-windows-x64-setup.exe。
2. 双击 EXE，确认安装位置、自启和自动更新选项，再点击“开始安装”。
3. 等待进度完成，点击“打开控制中心”。首次安装仍需联网准备 Python 和翻译依赖。
4. Zotero 插件的服务地址保持为 http://127.0.0.1:8890

首次安装可在向导选择自启，默认启用“登录 Windows 后自动启动”。登录后窗口不会弹出，控制中心会驻留托盘并确保服务运行。可以随时在“设置”中关闭此开关；升级不会改变该选择。

在“设置 → 外观与启动”中可选择跟随系统、浅色或深色。复制成功会就地反馈，错误详情可展开、滚动和复制。

安装进度

下载显示实际字节数、百分比和速度。准备环境、校验或健康检查等无法可靠计算总量的阶段，活动指示器表示仍在处理，不显示总体百分比，同时显示当前步骤和已用时间。操作详情和日志用于排查错误；重试保留已校验的下载。

自动更新

控制中心启动 60 秒后检查稳定版，此后每 24 小时检查。可在“设置”中关闭自动更新或手动检查。新版先在独立目录准备，连续空闲 60 秒后静默切换；任务、划词流式请求和词库下载期间不切换。失败时使用本地旧环境回退。

更新仍下载完整控制包和服务包。Python、未变化的依赖和模型字体缓存会复用；下载包通过校验后保留供失败重试使用，不使用二进制差分。

首次获得自动更新能力仍需手动运行一次新版安装 EXE。兼容 ZIP 保留给自动更新和故障恢复。旧版 EXE 不允许覆盖新版。

卸载

在控制中心“设置”菜单或开始菜单选择“卸载”。默认保留任务数据和日志；彻底删除请使用卸载脚本并确认删除数据。

目录

默认产品目录：%LOCALAPPDATA%\zotero-pdf2zh-pro
首次安装可以选择其他磁盘。控制中心、私有 uv、Python、缓存、数据和日志都位于所选产品目录。
已安装用户可以在控制中心更改位置；迁移失败时会恢复原安装。

故障恢复

安装目录 bin 下的 install.cmd、start-server.cmd、stop-server.cmd、view-log.cmd 和 uninstall.cmd，仅用于控制中心无法打开时的恢复操作。

系统要求与安全说明

- 需要 Windows 10/11 x64。控制中心使用 Rust + Slint Fluent 界面与 Skia 软件渲染，不需要 WebView2 或额外 VC++ 运行库。首次安装服务仍需要联网准备 Python 和翻译依赖。
- 旧用户运行新版安装 EXE 人工迁移一次，保留安装位置和自启选择。程序不卸载系统共享的 WebView2。
- 当前 EXE 未进行代码签名，Windows SmartScreen 可能显示警告。请只从本项目官方 GitHub Release 下载，并核对发布页 SHA-256。
- 程序不会创建 Windows Service、计划任务或防火墙规则，也不会停止占用 8890 端口的未知进程。
- 登录自启仅写入当前用户可见、可关闭的启动项，固定使用 --autostart 参数。
