zotero-pdf2zh-pro Windows 10/11 x64

1. Double-click install.cmd to install. Installation does not start the server automatically.
2. Use Start Server from the Start menu, or double-click start-server.cmd.
3. Set the Zotero plugin server address to http://127.0.0.1:8890
4. Run stop-server.cmd when the server is not needed.
5. Double-click uninstall.cmd to uninstall and choose whether to remove task data and logs.

Data directory:
%LOCALAPPDATA%\zotero-pdf2zh-pro\data

Log directory:
%LOCALAPPDATA%\zotero-pdf2zh-pro\logs

This package does not create a scheduled task, Windows Service, startup item, or logon item.
