# Windows Slint 迁移验收

[使用指南](user-guide.md#windows) · [构建说明](development-notes.md#windows) · [框架验证记录](windows-slint-validation.md)

2026-10-12，用户试用独立 Slint 验证程序后明确授权迁移。主控制中心已从手写
Win32 页面迁移为 Rust + Slint Fluent，版本仍为 1.8.2 开发候选，未公开发布。
安装和窗口体验由用户自行验证；本页区分已执行检查与待验证项目。

## 交付与使用

候选目录为 `dist/windows-slint-candidate/`，双击
`zotero-pdf2zh-pro-slint-candidate-setup.exe` 即可进入安装向导，无需旁置文件或解压。
完整安装器为 **35,237,571 字节（35.24 MB / 33.61 MiB）**，包含控制中心、脚本、
依赖清单、第三方许可证和现有服务 wheel，低于 40,000,000 字节上限。
SHA-256 随 `.exe.sha256` 和 `manifest.json` 提供。

候选默认使用 `%LOCALAPPDATA%\zotero-pdf2zh-pro-native-candidate`、端口 **19892**、
独立 HKCU 注册表和快捷方式。目录名延续上一候选，已有候选可进行同版本修复；
不要选择日常安装目录。首次安装仍需联网准备 Python 和大型翻译依赖。
需要测试 Zotero 连接时，将测试插件的服务地址设为 `http://127.0.0.1:19892`。

日常安装及其已启用的自启项未修改。旧 Win32 安装器和 Slint 框架验证程序均保留。
兼容自动更新 ZIP 位于同一候选目录，不需要用户手动解压安装。

## 已实现

- Slint 1.18.1、Winit、显式 `skia-software`，静态 CRT，界面编译进 EXE。
  没有 WebView2、浏览器进程或需要用户另装的 UI 运行时。
- 紧凑主面板、分组设置、三阶段安装向导、可滚动详情与复制反馈。
  主题支持跟随系统、浅色和深色；配置更新保留自启、更新选项及未知字段。
- 有总量时显示当前文件的字节数、百分比及速度；未知总量时显示活动指示器、
  当前步骤和耗时。沿用进度快照与安装事务，重试不会先显示上一操作的旧快照。
- 服务管理、调度与消息集中到 Rust 控制层；后台操作不在界面线程执行。
  保留托盘、单实例激活、资源管理器重启恢复、后台安装、健康检查和本地回退。
- 关闭面板会释放 Slint 页面并停止页面定时器，状态保留在控制层；再次打开恢复。
  保留系统标题栏、按 DPI 加载的图标、系统字体和文字缩放。
- 高对比度开启后，页面使用系统背景与文字颜色，忽略应用主题；框架内置控件
  目前按系统背景选择浅色或深色。**完整系统高对比度调色板仍需补齐验证，不能视为已通过。**
- 新构建入口准备固定 LLVM、Skia 与依赖，生成第三方许可清单；安装器构建强制
  40 MB 上限。CI 与发布脚本已改为相同入口，本轮未触发远程 CI 或发布。

## 用户验收与限制

1. 只复制候选 EXE 到中文或带空格的目录运行，测试首次安装与同版本修复。
   确认进度、错误详情、重试和完成后打开控制中心。
2. 测试启动/停止、复制地址、主题实时切换、设置滚动、中文输入法与复制粘贴。
   测试窗口关闭、托盘恢复和重复启动，核对后台操作继续且服务未误停。
3. 在实际可取得的 100%、150%、200% 缩放、系统字体大小、高对比度、键盘与
   屏幕阅读器条件下检查。框架验证曾收到“没什么问题”的反馈，未收到逐项设备记录。
4. 最终 GUI 的断网、磁盘不足、更新中断、等待空闲、实际升级与版本交接待验收。
   干净 Windows 10/11、普通用户和远程桌面设备兼容性也仍待验证。
5. 打开后关闭面板的工作集增量、持续重绘、启动用时、动画开销、首份 PDF 准备
   耗时及三次真实更新下载量未重测；目前没有声称这些门槛全部通过。

浅色、深色的实际截图待用户验收时采集；本轮没有用设计图或旧界面截图替代。

### 已实现

- 安装页标题显示当前步骤；移除重复说明和旋转指示器。未知总量只显示步骤、可得信息与耗时。
- 同页折叠详情、固定高度日志区、复制和日志入口、错误自动展开、暂停跟随和回到最新。
  界面关闭后保留内存状态，进度快照保存文件列表与最近日志，供重新打开和交接恢复。
- uv 0.12.10 仍负责下载、安装和缓存；隐藏 ConPTY 采集终端逐文件进度。
  使用 vt100 处理重绘与 UTF-8 分块，保留物理行边界；清理采集子进程中会抑制进度的
  `RUST_LOG`、`UV_NO_PROGRESS`、`TERM=dumb` 等环境影响。
- 文件列表按首次观察顺序固定，分别显示下载、解压、已下载或失败；新尝试显示重新下载和次数。
  界面进度最多每 250 毫秒更新一次，旧操作及较旧序号不能覆盖新状态。
- 进度值来自 uv 的终端字节采样；uv 本身以 KiB/MiB 舍入显示，因此这些数值不是网络层逐字节计数。
  没有合成整个安装过程的百分比；安装数量与下载百分比分开显示。
- 不支持 ConPTY 或 uv 版本不匹配时继续一次原有安装流程，显示实时进度不可用，不为采集重启下载。
- 关于页保留版本、AGPL-3.0-only 本地许可证和致谢；许可证与第三方清单加入安装候选复制，随事务提交与回退。
