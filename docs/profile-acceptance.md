# 翻译配置窗口验收

[使用指南](user-guide.md#api-configuration) · [接口兼容记录](provider-audit-2026-10-03.md)

安装本轮构建的 XPI，并使用同一工作区的服务端代码重启服务。不会自动安装插件、重启 Zotero 或替用户调用付费模型。

## 入口与布局

- [ ] 设置页只显示当前配置选择、管理配置及一行平台/模型/测试状态；无配置时显示“添加翻译配置”。
- [ ] 管理与编辑在同一窗口，选中配置不会改变“当前使用”；新增先显示平台分类且不预选平台或模型。
- [ ] 默认窗口约 1100×780，左栏宽 260px；在较小屏幕或高缩放下，窗口不超过屏幕可用区域减去 64px。
- [ ] 明暗主题、中英文、1100 / 920 / 760 / 700 / 400px 宽度、480px 高度及放大字号下，无横向溢出，底部按钮可见。
- [ ] 宽度不足 760px 时只显示顶部配置选择栏，完整列表和搜索隐藏；宽屏恢复左右分栏。长列表与右侧表单分别滚动，编辑字段不会使列表跳回顶部。
- [ ] 平台名称与更换入口位于右栏顶部；基础设置对齐排列，高级设置默认折叠。列表名称与模型分行，当前使用与未保存标记独立。
- [ ] 密钥只有一个显隐入口，切换配置后恢复隐藏；填写说明及长错误可以展开，不挤掉底部操作栏。
- [ ] 更多菜单支持方向键、Esc 和外部点击关闭，靠近窗口边缘时不被裁切。

## 配置与草稿

- [ ] 修改配置 A，切到 B 再返回，A 的草稿仍在；关闭有修改的窗口可取消退出。
- [ ] 新增 OpenRouter，地址为 `https://openrouter.ai/api/v1`；填写自己的密钥和模型后测试。
- [ ] 切到自定义兼容时不带入 OpenRouter 密钥；切回后恢复该平台的本次草稿。
- [ ] “保存”不切换来源；“保存并使用”切换来源；复制、置顶和删除可用，删除当前配置不自动选其他项。
- [ ] 获取模型失败仍可手填；成功不会自动选中首项。模型名、地址、密钥或协议变化后需要重新测试。
- [ ] 获取模型或测试期间切换配置，旧请求的结果不会覆盖新配置；再发起操作不会被旧请求阻塞。
- [ ] DeepL 隐藏模型，Codex/Claude Code 显示登录提示与高级 CLI 设置，Ollama 不显示无关密钥。

## 兼容与翻译

- [ ] 原有配置的 ID、地址、密钥、模型、协议和选文引用仍在；本轮移除的九种服务显示“需重新配置”且不能调用。
- [ ] 更换平台前可查看旧参数，保存后保持原配置 ID，全文与选文引用继续指向该配置。
- [ ] 使用自己的 OpenRouter 配置完成一次连接测试、短句翻译、流式翻译与停止，并抽测一份 PDF。
- [ ] 密钥错误、无权限模型、限流/额度和网络错误有提示；错误内容不暴露密钥。

自动验证使用模拟 API，不代替真实账号权限、网络及 Zotero 原生窗口的验收。

## 安装包资源与界面检查

先在 `plugin` 目录构建，再从仓库根目录运行 `node scripts/check_profile_ui.cjs <playwright模块路径>`。脚本直接读取 `plugin/build/zotero-pdf2zh-pro.xpi`，以 XHTML 类型加载其中的窗口页面及页面引用的 CSS/JS，并核对构建目录、安装包和资源构建标识。测试不手工注入样式，也不读取真实密钥或调用翻译服务。

检查覆盖 40 组语言、主题、宽度与字号组合，以及短窗口、长错误、独立滚动、键盘导航、草稿和配置操作；分别模拟缺失和旧版样式，确认能检出布局失效。隔离浏览器截图输出至 `.local-dev/profile-ui/`，与 Zotero 原生窗口验收分开记录。

- [ ] 同版本替换 XPI 后关闭旧配置窗口再打开，确认分栏、字体、底部按钮正常；开发热重载后也检查一次。
- [ ] 若仍异常，核对实际加载窗口的资源与当前构建是否一致；不要仅以浏览器截图作为原生窗口通过的证据。
