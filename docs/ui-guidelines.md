# 插件文案与 UI 规范

[开发维护笔记](development-notes.md) · [使用指南](user-guide.md)

本规范适用于 Zotero 插件的任务列表、设置、配置管理、划词界面、通知和对话框。
修改用户可见内容时遵守本规范；新增规则在这里维护，操作教程放使用指南，版本变化放 CHANGELOG。

## 文案原则

1. 用最少的文字让用户判断当前状态、结果和可执行的下一步。
2. 标题和控件已经说明用途时，不再添加页面介绍、重复计数或解释性副标题。
3. 标签、按钮、状态不加句号；完整说明和错误句子使用正常标点。
4. 按钮使用具体动词与对象，如“重试导入”“删除记录”。保留操作范围，不把“重试本页失败”缩成“重试”。
5. 没有信息价值的文字直接删除；必要但低频的规则放帮助或详情，不把所有删掉的文字搬到悬浮提示。
6. 不在正常界面展示堆栈、接口响应、内部字段名或实现细节；诊断数据继续保留在诊断包。

### 提示出现条件

| 情况 | 显示方式 |
| --- | --- |
| 正常运行、连接成功 | 就地显示简短状态，不追加解释 |
| 保存、复制、清除成功 | 必要时就地反馈约 4 秒；按钮或内容已表达结果时不再重复 |
| 加载与进度变化 | 更新同一位置，不随轮询重复播报 |
| 失败或需要用户处理 | 说明结果或原因，提供必要下一步；恢复前保留 |
| 会真实请求 API、覆盖内容、删除数据、丢失未保存修改 | 在相关操作附近保留影响判断的信息 |
| 少见机制、计量口径、配置继承规则 | 放使用指南或相关详情 |

普通提示的中文正文通常不超过 60 字，动态名称不计。复杂恢复操作允许更长，但先给简短结论。
同一事件选择一个主要展示位置；主动重试有反馈，后台轮询不重复通知。

### 本次整理示例

| 原内容 | 调整后 | 理由 |
| --- | --- | --- |
| 跟踪翻译进度、服务状态与附件导入结果 | 删除 | 标题和卡片已表达用途 |
| 重试和补译沿用原任务的复核设置，不受当前设置开关影响 | 放使用指南 | 属于操作规则，无需常驻页头 |
| 1/1 个已显示任务 | 删除 | 筛选标签已提供数量 |
| 当前列表／正在处理／需要处理／已完成统计卡片 | 合并至状态筛选的数量 | 同一数据只展示一次 |
| 事件流已连接 1/1 | 已连接 | 事件连接数保留在状态详情中 |
| 历史第 1 页 · 共 0 条 · 每个服务每页 30 条…… | 无历史时隐藏；有历史时在列表底部显示紧凑页码导航 | 分页规则放使用指南 |
| 剩余 / 吞吐：计算中 / 计算中 | 预计剩余：—；输出速度：— | 分开含义，缺失值不重复解释 |
| 尝试 | 尝试次数 | 明确数字含义 |
| 清理失败任务 | 清理失败记录 | 与任务停止操作区分，范围另作说明 |
| 配置页“翻译设置”副标题、平台选择页介绍 | 删除 | 重复页面或控件含义 |

## 术语与状态

| 概念 | 中文 | 英文 |
| --- | --- | --- |
| 当前列表筛选 | 全部／进行中／失败／已完成 | All / Active / Failed / Completed |
| 执行状态 | 排队中／运行中／正在终止／已终止 | Queued / Running / Stopping / Stopped |
| 中断后等待继续 | 待恢复 | Ready to resume |
| 仍有未完成段落 | 未完成 | Incomplete |
| 导入状态 | 待译文生成／等待导入／导入中／已导入／导入失败 | Awaiting translation / Awaiting import / Importing / Imported / Import failed |
| 单语输出／双语输出 | 单语译文／双语对照 | Translation only / Bilingual |
| 重新获取已有 PDF | 重试导入 | Retry import |
| 修复未完成内容 | 补译 | Repair |
| 删除任务及其服务端数据 | 删除记录 | Delete record |

执行状态与导入状态分别表达，不把“PDF 已生成”当成“全文翻译已完成”。
“待恢复”的中断类型和“未完成”的剩余段落数保留在状态详情中，不把长句塞进状态徽标。
校对摘要显示检查范围、修正数和问题数；完整覆盖范围与限制放“详情”，没有请求指标时也能展开。
未检查的段落不作“正确”或“通过”结论。

“重试本页失败”作用于当前加载列表中的失败任务，不受当前筛选标签限制。
“清理失败记录”作用于相关服务的全部失败记录，不能暗示只清理当前页；沿用现有删除流程。
是否禁用依据全部已加载记录中的失败任务；“未完成”和单独的导入失败不属于清理对象。
“继续上次队列”沿用原排队顺序。重试、补译和继续任务的设置继承规则见使用指南。

## 数字、时间与指标

- 未提供、未知或非有限数值使用 `—`，不能显示为测量值 `0`；真实零值正常显示。
- 百分比带 `%`。任务进度取整数，缓存命中率保留一位小数。
- 指标数量允许以 `K`、`M` 紧凑展示，详情保留完整数值；数字使用等宽数字样式。
- Token 顺序固定为输入／输出，摘要标签为“Token 入 / 出”，英文为“Tokens in / out”。
- 请求数量顺序固定为请求／重试；耗时顺序固定为均值／P95。详情提供完整指标名称。
- 紧凑耗时使用 `5 ms`、`5.9 s`、`2.4 min`、`1.2 h`，数值与单位之间留空格。
- 预计剩余时间按界面语言显示秒、分或小时；摘要输出速度为 `123.4 tokens/s`，段落/分钟放详情。
- 创建与更新时间使用界面语言的日期格式，并标明“创建”“更新”。
- 服务耗时包含排队和执行，不含停机及等待恢复；继续任务累加，重试或补译重新计时。
  异常退出前未保存的时间不估算，摘要显示“耗时（部分）”。摘要只保留总耗时，排队和执行拆分放详情。
- 输出速度为本轮执行最近 30 秒服务商回报的输出 Token 增量之和除以窗口时长；首次请求后不足 30 秒按实际时长计算，至少观察 1 秒。
  并发请求合计，重复及较旧的累计用量通知不重复计数；服务商计入输出的推理 Token 也包含在内。
  用量缺失或不完整时显示 `—`；已知用量但窗口内无新增输出时可显示 `0.0 tokens/s`。
  响应结束时才回报用量的服务按响应更新，不能描述为模型实时解码速度；结束任务展示最后一次快照。
  继续任务重新统计速度窗口，旧累计用量不进入新窗口；段落速度继续用于进度观察和剩余时间估算。

## 布局与视觉规则

沿用插件现有组件样式和颜色变量，避免为单个界面新增一套视觉系统。
任务窗口的主要变量为 `--surface`、`--text-primary`、`--text-secondary`、`--text-tertiary`、
`--border`、`--accent`、`--success`、`--warning`、`--error`；浅色和深色分别定义值。

| 项目 | 任务窗口基准 |
| --- | --- |
| 正文 | 13 px / 20 px |
| 页面标题 | 20 px / 28 px，字重 600 |
| 文件名 | 14 px / 22 px，字重 600 |
| 标签与次要信息 | 11–12 px，保持清晰可读 |
| 间距 | 以 4 px 为基础，常用 8、12、16、20、24 px |
| 卡片内容左右边距 | 16 px；页脚为 12 px |
| 普通按钮 | 最小高度 32 px；卡片内紧凑按钮为 28 px |
| 卡片圆角 | 12 px；内部指标框为 8 px |

上述数值用于现有任务窗口；Zotero 原生设置控件继续使用宿主样式。
新组件优先复用所在界面的样式，确需差异时在这里说明原因。

### 页头和操作

- 任务页顶部正常状态只保留两行，归入同一轻量区域：第一行放标题、连接状态、刷新和关闭，第二行放筛选和批量操作。不要为每行添加独立卡片和阴影。
- 筛选标签保留数量；队列、批量重试和清理操作放筛选区，按用途分组。
- 同组按钮高度、间距、基线一致；破坏性操作与普通操作拉开距离。
- 没有明确主要操作时，不强行设置主按钮。红色用于错误和破坏性操作。
- 无可操作对象时使用禁用状态，不用常驻说明解释禁用；控件状态变化不应导致无关按钮跳位。
- 宽度不足时整组换行；刷新与关闭保持一组，避免“关闭”单独掉行。
  按桌面窗口的实际可用宽度调整，常用宽度内不让单个按钮掉行。

### 任务卡片和指标

- 阅读顺序为文件与状态、阶段和进度、时间、必要结果、指标与操作。
- 标题、进度、时间、校对摘要与错误内容沿同一内容边界对齐；耗时并入指标栏，不另占一行。
- 长文件名在宽窗口省略并提供完整标题，窄窗口允许换行；状态徽标保持简短。
- 指标区始终隐藏横向滚动条，保留横向滚动和键盘方向键浏览能力。
  保持 `overflow-x: auto`、`scrollbar-width: none` 及 WebKit 滚动条隐藏规则；不能改为裁切后不可滚动。
- 指标区域可聚焦，有明确的可访问名称；焦点轮廓不能被去掉。
- 宽度不足时，操作区整体移到下一行；更窄时按钮允许换行，不能覆盖指标。
- 摘要指标自然占宽，单个标签和数值不拆开；完整诊断及校对覆盖范围放详情。
- 不因滚动条隐藏而添加常驻“左右滑动”等说明。

### 设置表单

- 标题与“新功能与帮助”在同一行，帮助使用轻量文字入口。版本与正常连接状态在下一行紧凑显示，不使用大卡片。
- 内容最大宽度 860 px，统一左侧边界；区块上下间距约 18 px，标题与控件间距 12 px。
- 语言和选文设置采用等宽两列，列间距 20 px；字段标签在上，控件在下。语言代码是同组紧凑输入，保留自定义能力。
- 普通选择框、文本框、按钮统一 32 px 高度；重置宿主默认外边距，保留原生控件交互、主题与焦点。
- PDF 输出按“输出格式”“完成后”“附件命名”分行。行标签列 100 px，间距 16 px；复选项使用同一列网格，框与文字基线对齐。
- 附件标题编辑器展开后占满区块宽度，与区块左边缘对齐，不继承设置行的标签列缩进。折叠或关闭功能时不能留下空白区域。
- 字段块内的移动和删除使用紧凑图标按钮（24 px），保留键盘操作、禁用和焦点状态；不能继承普通按钮的最小高度与内边距。
- 分隔符预设与带标签的自定义输入保持成组，统一为 28 px；字段块内的文本输入为 24 px，紧凑控件的尺寸规则必须覆盖通用输入样式。桌面常用宽度内不让输入框单独掉行。标题预览使用紧凑两行，避免重复大容器和过宽标签列。
- 配置摘要不重复选择框中已有的模型；“划选单词查词”等介绍性文字删除。高级选项保留在对应功能的折叠区域内。
- 高级参数采用等宽两列，数字输入与选择框同高；选项组与上方表单间隔 16 px。不要用三列放四个字段，让最后一项孤立。
- 常规按钮为 32 px；列表行、词库管理和导入清理等次要工具栏使用 28 px。与选择框并排的“管理配置”保持 32 px；尺寸由明确组件类控制，不能对所有工具栏统一缩小。
- HTML 复选框使用 16 px；同组的框、文字和禁用状态对齐。复选项正常行高不小于 32 px，长标签允许自然换行。
- 折叠标题关闭时不保留内容间距，展开后与内容间隔 8 px（整块高级参数为 16 px）。内嵌表单用网格 gap 管理间距，隐藏条件字段不占位。
- 服务连接使用完整地址输入框，下方以 8 px 间距并排放检查和导出操作；结果与操作间隔 12 px，长错误文字可换行。
- 长来源、许可链接和词库校验值在区块内换行，保留完整内容；说明放在相关控件附近，不在词库操作下堆叠其他功能的提示。
- 设置样式集中维护在 `plugin/addon/content/preferences.css`，规则限制在 `.pdf2zh-pref-pane` 内，避免与 Zotero 默认表单样式争用；在原生窗口核对实际位置。样式链接携带构建标识，确保开发热重载使用当前版本。

### 新功能与帮助

- 阅读顺序为当前版本摘要、使用帮助、历史更新与完整文档；当前版本始终可见，历史版本使用一个默认收起的原生 `details`，没有历史时隐藏折叠入口。
- 更新摘要每版最多三项，每项只讲一个变化，优先描述用户可感知的结果；保留升级前提等必要条件。更新列表只放文字，不在每条末尾重复添加操作按钮。
- 帮助按 PDF 翻译、选文翻译、配置与登录、故障排查组织为等宽两列。每个主题只有一个标题链接，直达对应指南章节，下方用一句话概括操作；不再同时放功能跳转与指南按钮。
- “使用指南”和“完整更新记录”在页尾各保留一个文字链接。链接使用真实地址、可辨识的下划线和键盘焦点，由 Zotero 打开；不使用按钮模拟文档链接。
- 页面标题 20 px / 28 px，区块与版本标题 14 px / 20 px，正文 13 px / 20 px，辅助说明与页尾链接 12 px / 20 px；同一内容边界对齐，正文与链接不互相挤占。
- 页面左右内边距 24 px，内容最大宽度 760 px；区块之间以轻分隔线与 16–18 px 间距区分，不增加卡片、导航栏或重复副标题。
- 更新摘要离线可读；帮助链接按需联网，不在打开窗口时预加载文档。更新提示卡片优先使用条目的 `cardMessage` 短摘要，未提供时回退到 `message`；帮助页使用完整 `message`，保留功能条件和细节。
- 更新提示卡片按插件名称、更新结果、最多三条短摘要、操作区排列，不另加服务升级提示。插件名称为 12 px / 18 px，更新结果为 16 px / 24 px、字重 600，正文为 13 px / 20 px；“查看更新详情”使用轻量文字按钮打开本地帮助窗口，“关闭”使用普通按钮。卡片与帮助页样式分别限定在 `.pdf2zh-update-card` 和 `.pdf2zh-help` 内。
- 验收覆盖当前摘要、历史展开与收起、首屏帮助、六个文档链接、Tab 焦点及 Escape 关闭；沿用桌面尺寸与深浅色检查，中英文结构及章节目标必须一致。

### 空间、主题与可访问性

- 不用固定最小页面宽度制造整页横向溢出；任务指标区域允许自身横向滚动。
- 以 Zotero 原生桌面窗口及合理的横向缩放验收，记录实际尺寸。默认不做手机宽度、竖版或无关极窄断点检查。
- 状态既有文字也有颜色。键盘可访问所有可操作控件，焦点可见。
- 折叠控件维护 `aria-expanded` 与 `aria-controls`，展开状态在任务刷新时保持。
- 历史分页放在任务列表底部右侧，使用上一页箭头、页码、下一页箭头；箭头具有可访问名称。无历史记录时隐藏分页；空列表只显示简短空状态。
- 浅深色、中英文使用同一结构和功能，不为缩短英文而省略操作范围。

## 维护入口

| 内容 | 位置 |
| --- | --- |
| 通用与任务窗口文案 | `plugin/addon/locale/{zh-CN,en-US}/addon.ftl`，任务键使用 `task-ui-` 前缀 |
| 设置文案 | 两种语言的 `preferences.ftl` |
| 设置结构与样式 | `plugin/addon/content/preferences.xhtml`、`preferences.css` |
| 任务结构、局部样式与渲染 | `plugin/addon/content/taskManager.xhtml` |
| 任务窗口的语言及操作接口 | `plugin/src/modules/pdf2zhTaskManager.ts` |
| 配置界面 | `llmApiManager.xhtml`、`profileManager.css` 及配置编辑模块 |
| 提示规则的实现 | `plugin/src/modules/userNotice.ts` |
| 更新与帮助窗口 | `noticeHelp.xhtml`、`noticeHelp.js`、`notices.css`；摘要清单为 `plugin/src/modules/releaseNotes.ts` |
| 真实操作和计量口径 | [使用指南](user-guide.md#task-management) |

用户可见文案集中在本地化资源中，不新增散落在模板或脚本中的中文常量。
模板使用消息标记，动态内容使用具名参数；中英文键与参数同时修改。
动态状态码不直接成为用户文案，未知状态给出稳定的通用状态。
正式文库、密钥、接口地址和用户论文不写进示例、规范或验证快照。

### 修改流程和验收

1. 阅读本规范，定位现有组件及其本地化入口，核对操作的真实范围。
2. 修改中英文文案与界面；规则有变化时同步更新本规范和对应指南。
3. 运行插件类型、格式、现有测试和文档检查；状态、范围、未知值等行为用有意义的测试覆盖。
4. 用独立开发 Zotero 检查实际渲染、资源重载和交互；不安装到正式 Profile。
