# ChatGPT 套餐登录、统计与回退

[使用指南](user-guide.md#使用-chatgpt-套餐登录) · [测评工具](translation-benchmark.md)

插件的 `chatgpt` 通道使用独立的 ChatGPT 授权，通过官方 Responses 接口翻译。它不读取 Codex 的登录文件，也不需要安装 Codex CLI。OpenAI API Key 配置仍属于单独的 `openai` 通道。

## 登录与账号

在配置管理中选择「官方 → ChatGPT（使用套餐）」，点击「使用 ChatGPT 登录」。浏览器授权页面会说明应用与套餐权限；完成后返回 Zotero，获取模型并测试。模型列表查询不发送生成请求，点击测试会消耗一次短翻译请求。

登录使用 PKCE、state、nonce 和签名校验。凭据仅存于本机服务的数据目录 `chatgpt-auth/`，插件偏好只保存账号指纹。所有 ChatGPT 配置共用当前授权；切换账号后，旧账号绑定的配置会要求重新测试，不能静默使用新账号。翻译进行中不能切换或退出账号。取消浏览器授权不会替换已有会话。

访问令牌临近过期时自动续期，跨线程与进程的续期串行并原子替换凭据。退出会尝试撤销本应用的刷新令牌；无法确认远端撤销时仍退出本机，并提示前往 ChatGPT 设置断开应用。退出不删除本地用量账本，也不影响 Codex 登录。

自动续期成功不弹提示。实际请求确认授权已失效或无法续期时，配置页显示「ChatGPT 登录已失效，请重新登录」，选段结果和全文任务也提供「重新登录」按钮。点击后打开配置页及浏览器授权；完成后手动重试翻译。临时网络故障提示检查网络重试，不会把账号标为登录失效。配置页在测试、获取模型后及重新获得焦点时刷新账号状态，不在后台定时进行授权检查。

若模型查询或翻译在接受响应流之前返回 HTTP 401，先尝试续期并最多重发一次。并发请求共用已轮换的新令牌；期间切换账号或取消任务，不会继续发送翻译。刷新令牌被撤销或重发仍返回 401 时才要求重新登录。已接受的响应流、部分译文及连接中断不会进入这条自动重发路径。

默认存储位置跟随服务任务数据目录，可通过 `PDF2ZH_CHATGPT_AUTH_DIR` 指定独立持久目录。不要复制同一刷新令牌到两个独立目录分别续期，令牌轮换可能使另一份失效。不要把凭据目录加入 Git、诊断包或公开测评包。

本轮登录管理仅支持运行在同一电脑上的原生服务（源码、PyPI、Windows 本地服务或 Homebrew），账户接口拒绝浏览器跨域访问和非回环请求。Docker 网络隔离、远程服务、SSH 转发场景尚不提供登录向导，请使用原生本地服务；不要通过放开账户接口访问限制来绕过这个边界。其他 API Key 通道的 Docker 使用方式不变。

ChatGPT 网络请求跟随服务启动环境的 HTTP(S) 代理；原 Codex 配置的专属代理和 CLI 路径保存在本地备份中。新建 ChatGPT 配置后须测试网络与模型权限。

## 用量显示的含义

ChatGPT 正文翻译默认最多同时执行 24 个模型请求，QPS 上限为 3；用户设置更低的并发数或 QPS 时按更低值执行。正文与术语抽取共用任务的并发槽位；QPS 相同时也共用请求限流器。该数值是插件服务的本地执行配置，不代表官方接口的并发上限。

登录界面保留「管理 ChatGPT 套餐用量」按钮，用于打开官方用量设置。调用次数和 Token 明细由本机服务继续记录，可通过 `/chatgpt/usage` 查询，不在登录界面展示。账本记录实际生成调用次数，以及已知输入、输出、缓存输入 Token 和用量不完整的调用数。缓存输入是输入 Token 的子集，不再次相加。记录按账号和应用授权绑定区分；同账号重新创建独立授权时不会自动合并旧授权的记录。

- 使用调用 ID 去重；累计事件不会重复相加，批次用量不会按段落倍增。
- 翻译、术语抽取、质量审查和初始化保留各自调用目的；登录、模型查询、本地缓存或翻译记忆命中不算生成。
- 失败或取消仍保留已经收到的用量。断流或进程强制结束且未收到最终用量，保留为未知，不能补零。
- 401 原请求与续期后重发分别记为两次调用；原请求无用量回执时记为未知。重发受同一请求预算和限流约束，调用流水以 `auth_refresh` 关联原请求；模型查询和续期交换本身不计生成。
- SQLite 账本跨服务重启保留，仅存统计字段，不存授权令牌、原文或译文。清空数据目录会丢失本机历史。
- 当前没有已验证的公开接口能返回这个独立授权通道的完整套餐已用百分比。套餐用量请查看 [ChatGPT 官方用量设置](https://chatgpt.com/settings/usage)。Token 不能换算套餐百分比，Codex 配额窗口也不能冒充此通道的额度。

服务返回套餐或应用限额错误时停止该任务继续发起请求；普通限流和暂时不可用保留可重试分类。除上述受控 401 续期外，PDF 重试仍由产品的失败项恢复机制管理。纯模型测评关闭 401 自动重发，保留首次失败。中断本地连接不能证明提供方已经停止生成；这种情况用量可能未知。不会自动改用付费 API Key 或另一账号。

## 迁移与回退

插件启动或读取配置时自动删除旧 Codex 翻译配置，并提示改用 ChatGPT 登录。已绑定旧配置的全文默认项会清空；独立选段的旧配置引用显示为已删除，等待用户重新选择，避免自动切换到其他模型。其他提供方与已有 ChatGPT 配置保持不变。

在设置中新增「ChatGPT（使用套餐）」配置，登录、获取模型并测试后保存使用。当前配置菜单不再提供恢复 Codex 的入口；重新导入旧 Codex 配置也会被清理。

首次清理前，将原配置与选择项快照保存到本地偏好 `codexRetirementBackup`。已有 `chatgptMigrationBackup`、`chatgptCodexBackups`、`chatgptPreRollbackBackup` 等历史备份保持原样，仅供必要时配合旧版本手动恢复；当前版本不会自动恢复或使用它们。备份可能含其他服务密钥，不应直接分享。

## 维护与验证

`chatgpt_auth.py` 管理授权；`chatgpt_client.py` 管理 Responses 流、错误分类和取消；`chatgpt_usage.py` 记实际请求账本。公共调用统计与限流位于 `AccountTranslator`，原 Codex 后端保留供历史回归和旧版本兼容，当前插件不再使用旧配置。

离线测试覆盖签名、state、nonce、账号绑定、并发续期、撤销失败、重复事件、失败用量、等响应头时取消，以及旧配置清理、备份与一次性提示。普通 CI 不调用真实模型。真实回归使用 `provider: "chatgpt"` 的正式产品入口，须显式 `--execute` 并配置调用数、时间上限。

真实运行结果须保留代码指纹、输入版本、模型与推理档位。取消、重启和故障案例单列，不混入质量分数。单次验收只能说明本次调用情况；性能改善须另做相同配置的至少三次配对运行。本功能验收不晋升测评基准。
