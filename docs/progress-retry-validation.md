# 进度、重试与推理模式修复验证

验证日期：2026-09-23。

## 行为变化

- 参考文献与阶段总数使用相同的有效段落范围，预先计数后不再参与逐页或跨页翻译。427 段场景的中途计数为 416/427，最终为 427/427。
- 阶段和总百分比限于 0–100%，原始越界计数留在诊断日志中。取消或异常退出不会强制发布阶段完成。
- OpenAI 兼容翻译的多段批次首次超时即拆段；格式错误仅修复无效部分。永久错误、限流或服务端错误耗尽重试后不会拆段放大请求。
- 一次任务执行中，每段最多参与三次实际翻译请求；每个具体请求最多尝试两次，累计退避最多 30 秒。批量和回退共用预算，缓存命中不扣预算，主动重试任务获得新的预算。
- 原有默认 120 秒请求超时、用户指定超时、QPS、并发、模型和语义校对设置保持不变。初始化与校对保留各自预算。
- 任务卡片删除统计说明小字及空白节点；主要统计数值保留，未知值仍为 `-`。运行中使用一条简短阶段状态展示等待响应、重试或拆段处理。

## 配置兼容

API 配置新增可选的 `llm_api.reasoningMode`：`default` 保持现有行为，`off` 关闭推理。健康检查中的 `capabilities.reasoningMode` 标识服务端支持能力；旧服务器不会静默忽略关闭设置。

快捷关闭支持 DeepSeek V4 Flash/Pro、DeepSeek Flash，以及 GPT-5.1、5.2、5.4、5.5 基础型号和日期快照。未知型号及 OpenAI Pro/Codex 等未明确支持的变体不可使用快捷关闭，仍可使用原有高级 JSON 参数。

DeepSeek Chat Completions 使用 `thinking.type=disabled`；OpenAI Chat Completions 使用 `reasoning_effort=none`，Responses 使用 `reasoning.effort=none`。冲突参数明确报错。有效参数隔离翻译和校对缓存；恢复指纹忽略显式的 `default` 字段，保留旧任务兼容性。

API 测试独立显示推理设置的观测结果：仍有推理 Token 时提示可能未生效，未报告时说明无法确认，报告零时只说明本次测试值为零。任务卡片不显示这段诊断文字。
