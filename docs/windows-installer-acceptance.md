# 单 EXE 安装验收

[使用指南](user-guide.md#windows) · [原生基础验收](windows-native-acceptance.md) · [构建说明](development-notes.md#windows)

记录日期：2026-10-12。版本保持 1.8.2，这是尚未公开发布的候选构建。

## 交付及实现

构建生成 `zotero-pdf2zh-pro-windows-x64-setup.exe`，一个文件内置控制中心、管理脚本、
锁定依赖清单和对应服务 wheel。用户双击后进入原生安装向导，无需解压或执行命令。
Python 和大型依赖在首次安装时联网准备；已校验下载与兼容缓存可供重试和后续更新复用。
安装完成后，已安装控制中心独立运行，不携带整份载荷。XPI 继续单独安装。

另外生成 `zotero-pdf2zh-pro-native-candidate-setup.exe`，默认安装到当前用户的
`%LOCALAPPDATA%\zotero-pdf2zh-pro-native-candidate`，使用 19892 端口、私有注册表和快捷方式目录。
候选自启选项只写隔离测试键，不加入系统登录启动列表；日常安装及其已启用自启保留。
安装目录的候选标记使直接启动快捷方式和恢复脚本也沿用隔离设置。

日常面板为 380 × 280 逻辑像素，安装向导为 480 × 360；系统字体、标准按钮、浅色背景，
安装路径与维护选项移入“更多”。向导包含设置、进度和完成页面；失败提供重试、详情和日志。
安装及手动操作可收起到托盘，切换期间不能通过退出按钮中断事务。

下载有明确总量时显示真实字节、百分比和采样速度；依赖准备等阶段显示活动进度条、步骤和耗时，
说明“当前阶段无法估算百分比”。活动动画只在状态变化时启停，避免每次刷新重新开始。
进度快照供重新打开面板与实例交接展示，事务日志仍负责恢复判断。

手动安装发现 Windows PowerShell 5.1 继承 PowerShell 7 的模块路径后，无法加载
`Get-FileHash`。修复为流式 .NET SHA-256，并限制管理脚本使用 Windows 自带模块目录；
Rust 子进程清除继承的模块路径。回归测试主动设置污染的模块路径，同时关闭模块自动加载验证哈希。
用户重试后完成安装。该次安装有预置开发缓存，不能代表新设备首次依赖下载量。

## 体积与性能数据

最终字节数及 SHA-256 以交付目录的 `manifest.json` 和独立 `.exe.sha256` 为准。
单 EXE 约 24.4 MB（23.3 MiB），其中服务 wheel 约 21.1 MB；已安装控制中心约 6 MB。
自动更新仍使用控制 ZIP 与服务 wheel，不重复下载安装器。

上一轮控制 EXE 为 5,842,944 字节，历史网页控制 EXE 为 14,530,560 字节。
本轮加入向导与进度后仍明显小于历史控制 EXE；安装器和控制 EXE 用途不同，不能直接比较。
旧采样的启动时间、内存和三次同版离线更新数据见原生基础验收。本轮没有重新采样这些指标，
不将旧数字当作当前安装器或新版 UI 的测量结果。
