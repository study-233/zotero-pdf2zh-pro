测评口径与来源

计算机论文英译中，每组 240 条正式样本；总览每模型展示一条配置，并同时保留 GPT 的 Command Code 与插件账号两组结果，均经评阅与复核。无输出计 0 分，耗时取成功请求。评阅非独立。

接入来源表示实际测评通道，区别于模型厂商；GPT 的 Command Code 组使用 Responses / 关闭推理，插件账号组使用 Responses / low。各组接口、推理设置与测试日期见上表，跨日期结果仅作观测对比；前沿线描述图中配置的观测关系。提供方默认表示未显式指定推理开关。

金额按已记录 Token 计价，含预检和复测；≥ 表示缺少部分用量回执，实际现金扣费未核实。插件 GPT 账号的费用以 ≈ 标记为 API 等值估算，不代表账号套餐实际扣费。完整数据保留全部接口、推理开关及插件 GPT 账号的测评记录。
