<span id="1-安装前准备"></span>

<span id="quick-start"></span>

Windows 10/11 x64 和运行 macOS 14 或更高版本的 Apple Silicon Mac 使用同一个插件。

<span id="需要安装哪些东西"></span>

## 首次使用

1. 安装 [Zotero 8–10](https://www.zotero.org/download/)。
2. [安装 XPI 并检查本地服务](/zotero-pdf2zh-pro/guide/installation/)。首次确认后，插件自动下载并启动引擎，需要联网。
3. 准备翻译服务的 API Key，或使用已有的 [ChatGPT 套餐或本地模型](/zotero-pdf2zh-pro/guide/api-configuration/)。

已有服务继续使用原地址和原来的数据目录。Windows 控制中心、Homebrew、uv 和 Docker 的维护入口均保留。Linux 用户请查看[进阶部署](/zotero-pdf2zh-pro/guide/advanced/)。

<span id="两种地址不要填反"></span>

## 地址与费用

- **本地服务地址**：`http://127.0.0.1:8890`，填写在插件的“服务端连接”中。
- **API 地址**：由模型服务商提供，填写在翻译配置中。两者不能混用。

PDF 在本地处理；云端翻译会把待译文本发送给所选服务商，并使用其额度。

> [!TIP]
> 第一次用一篇较短、能选中文字的 PDF 测试。保持“禁用术语提取”开启，可减少额外 token 消耗。
