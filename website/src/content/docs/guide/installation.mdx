<span id="4-安装-zotero-插件与检查连接"></span>

<span id="installation"></span>

Windows 和 macOS 使用同一个 XPI。Windows 10/11 x64、Windows 11 ARM64 和 Apple Silicon Mac 可在插件内安装本地引擎；已有独立或远程服务可继续连接。

<span id="安装-xpi"></span>

## 安装插件

[下载 XPI](https://github.com/study-233/zotero-pdf2zh-pro/releases/latest/download/zotero-pdf2zh-pro.xpi)。打开 Zotero **工具 → 插件**，在齿轮菜单选择 **Install Plugin From File…**，选中 XPI 并按提示重启。

![在插件管理器中选择从文件安装 XPI](/zotero-pdf2zh-pro/assets/guide/install-plugin.webp)

<span id="打开设置并检查本地服务"></span>

## 安装引擎并检查连接

1. 在 Zotero 设置中打开 **zotero-pdf2zh-pro → 翻译服务**。
2. 点击 **安装本地引擎** 使用默认目录，或点击 **选择安装位置…** 选择上级文件夹。确认路径后等待下载完成。
3. 插件准备好引擎后自动填写本机地址。显示 **已连接** 后，继续配置翻译来源。

![翻译服务显示插件托管引擎、安装与数据目录，以及更新选项](/zotero-pdf2zh-pro/assets/guide/server-connected.webp)

继续[配置翻译来源](/zotero-pdf2zh-pro/guide/api-configuration/)。之后可在同一处使用 **更改安装位置…** 迁移引擎和后端数据。

## 连接已有服务

使用 Windows 控制中心、Homebrew、uv、Docker 或远程服务时，先按原方式启动服务，再填写原地址并点击 **测试连接**。本机默认地址为 `http://127.0.0.1:8890`；保留原数据目录，无需迁移到插件引擎。

Intel Mac、Linux 或需要独立管理服务的用户，可使用已有服务或[其他部署方式](/zotero-pdf2zh-pro/guide/advanced/)。
