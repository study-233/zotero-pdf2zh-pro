# 官网设计

官网使用 Next.js、React、Tailwind 和 Fumadocs。营销页共用导航、字体和颜色。组件来源见[源码记录](SOURCES.md)。

- 首页用双语论文和划词实机截图展示阅读效果。保留图片比例、替代文本、键盘操作和焦点反馈。
- 安装页按平台提供下载或可复制命令。教程用截图指出操作位置，每步写明动作或完成状态。
- 用户可见的版本、下载和步骤与最新正式 Release 一致。教程保留旧路由和锚点，测评保留已出版的数据与附件。
- 页面修改后核对手机和桌面、浅色和深色以及减少动画偏好。见[构建与验证](README.md#验证与回退)和[截图来源](screenshot-todo.md)。
