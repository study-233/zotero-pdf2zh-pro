## 来源与审核

- Windows 11，Zotero 10.0.6，插件、服务和 Windows 控制中心 1.9.7。
- Zotero 使用隔离文库，示例为公开论文 Attention Is All You Need；截图不含账号、密钥或私人文献。
- 单词结果来自实际有道查询，句子结果来自实际必应翻译；全文双语图和任务指标展示已有真实翻译结果，本轮未重新请求全文翻译。
- Windows 安装图只展示未提交的安装路径，未执行安装；就绪图来自实际运行的服务。
- API 图片为未填写密钥的真实配置表单，不代表已通过某个 API 模型测试。
- 通过原生窗口和 Zotero 绘制接口截图；仅裁切、缩放和编码 WebP，没有生成或仿制产品 UI。
