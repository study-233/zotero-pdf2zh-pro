# Release 文案

从上次正式版的 tag 核对到本次提交，用中文写用户能观察到的变化。正文取自 CHANGELOG 对应版本。

- 一句话概括本版，按影响列出主要变化。每条写清触发条件和结果，短补丁可只写一条。
- 只有用户需要采取操作时才加升级说明。核对本次制品的托管引擎支持平台、独立服务更新方式及数据保留行为。同版本替换应点明哪些包需要手动更新。
- 结尾链接到实际安装包、对应安装指南和与上一正式版的完整变更。使用后续合入的文档时链接官网指南。哈希、测试记录和 Actions 日志保存在机器记录中。

仅编辑已发布版本的正文时，使用 `gh release edit --notes-file` 并回读结果。
